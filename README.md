# Magic Battle · CC LAB

Браузерная AR-игра, в которой тело игрока становится контроллером. MediaPipe распознаёт позы, кисти, удары и уклонения, а Three.js рисует магические эффекты поверх камеры.

## Что внутри

- сюжетная кампания из 5 глав с двумя финалами;
- режим «Задание» с одним случайным стражем и отдельным результатом;
- бесконечный режим «Апокалипсис» с непрерывными, постепенно усиливающимися волнами;
- синтезированные звуки заклинаний, ударов, побед и фоновая музыка с выключателем;
- обязательное обучение при первом запуске с сохранением отметки о прохождении;
- 16 заклинаний, 4 боксёрских удара и система комбо;
- адаптивное сглаживание скелета и защита от случайного сброса жеста;
- отдельное распознавание кистей, калибровка и индикатор качества захвата;
- демо-режим без камеры;
- подключение камеры телефона через `phone-cam-cc-lab.html`;
- автоматическое размытие неприличного жеста со средним пальцем;
- раздел дополнительных игр прямо в меню Magic Battle;
- `block-catcher.html`: ловите фигуры, поворачивайте их наклоном кисти и собирайте ряды;
- `shadow-racer.html`: гонка с невидимым рулём из двух рук;
- `rune-shooter.html`: 2D-стрелялка от первого лица с прицелом на указательном пальце;

## Запуск

Камера браузера работает только на `localhost` или через HTTPS. Для локальной проверки запустите любой статический сервер в папке проекта и откройте `index.html` через него.

На первом экране нажмите «Проверить камеру». Хороший результат калибровки — от 62%. Встаньте по центру, покажите обе кисти и добавьте света перед собой.

## Технологии

HTML, CSS, JavaScript, MediaPipe Pose + Hands, Three.js и PeerJS. Сборка не требуется.
